# 🍅 Tomato Disease Detection AI

An AI-powered **Tomato Disease Detection System** that uses **Deep Learning, Machine Learning, and Computer Vision** to identify diseases from tomato leaf images.

## 🌱 How It Works

The system follows a simple **two-stage intelligent detection workflow**:

```mermaid

    B --> C["🧠 Deep Learning Model"]

    E --> F["💊 Treatment & Management"]
```

### 🔄 Detection Pipeline

**1️⃣ Upload** → The user uploads a tomato leaf image.

**2️⃣ Preprocessing** → The image is resized, normalized, and prepared for AI analysis.

**3️⃣ Deep Learning Analysis** → The trained model extracts important visual patterns from the leaf.

**4️⃣ Disease Detection** → The AI compares the detected patterns with learned disease characteristics.

**5️⃣ Prediction** → The system identifies the most probable disease and displays its confidence score.

**6️⃣ Treatment Guidance** → Relevant treatment and management information is displayed.

**7️⃣ Final Result** → The user receives an easy-to-understand plant health diagnosis.
